# Diabetes Risk Analysis Dashboard Using Excel

## Project Overview
This project uses Microsoft Excel to explore a synthetic diabetes risk dataset. The original dataset contains 50,000 patient records and 41 features. For this project, I extracted and analyzed a sample of 10,000 records.

The analysis focused on diabetes risk classifications, selected health indicators, data cleaning, and dashboard development.

## Dataset Information
- **Dataset:** Diabetes Risk Prediction Dataset (50K patients)
- **Original size:** 50,000 synthetic patient records
- **Sample analyzed:** 10,000 records
- **Features:** 41
- **Source:** Kaggle
- **Creator:** Mobeen Fatima
- **License:** CC BY-SA 4.0

**Original dataset:**  
https://www.kaggle.com/datasets/mobeenfatimah/diabetes-risk-prediction-dataset-50k-patients

## Tools and Techniques
- Microsoft Excel
- Data cleaning and validation
- Median and mode imputation
- PivotTables and PivotCharts
- Data visualization and dashboard design

## Data Preparation
- Checked for missing values and duplicate records.
- Replaced missing numerical values using median imputation.
- Replaced missing categorical values using mode imputation.
- Prepared the cleaned data for analysis.

## Key Findings
- High-risk records accounted for 73.9% of the 10,000 records analyzed.
- Average HbA1c and BMI increased across all three categories: Low, Moderate, and High.
- Average total cholesterol also increased across the risk categories.

## Project Files
The Excel workbook includes:
- Cleaned dataset
- PivotTables and PivotCharts
- Primary Dashboard
- Vitals Dashboard
- Clinical terminology glossary

## Limitation
The dataset is synthetic and does not represent actual patients. Findings describe patterns within the selected sample and should not be interpreted as real-world clinical outcomes.
